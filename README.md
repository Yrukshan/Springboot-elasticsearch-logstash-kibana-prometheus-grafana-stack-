# Springboot-elasticsearch-logstash-kibana-prometheus-grafana-stack-
Spring Boot application with Elasticsearch, Logstash, Kibana, Prometheus, and Grafana for centralized logging, monitoring, and observability.

## Project Description

This project is a Spring Boot Observability and Monitoring Stack designed to learn and implement modern backend system monitoring, logging, and performance tracking techniques.

## It integrates the following technologies:

### Spring Boot – Backend REST API development
### Elasticsearch – Log storage and search engine
### Logstash – Log processing and pipeline management
### Kibana – Log visualization and analysis
### Prometheus – Metrics collection and monitoring
### Grafana – Dashboard creation and system visualization

## Project Status

This project is currently in development (ongoing).
Features and integrations are being implemented step by step as part of a learning and research process.

## Goals

### mplement centralized logging using ELK stack
### Collect application metrics using Prometheus
### Visualize system performance using Grafana
### Understand observability in microservices and Spring Boot applications
### Build a foundation for advanced DevOps and self-healing systems

## Purpose

This project is mainly for learning and hands-on practice of modern observability tools used in real-world production systems.
